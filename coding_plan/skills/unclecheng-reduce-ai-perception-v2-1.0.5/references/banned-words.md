## 一、最毒禁用句式（出现即修，最高优先级）

| 毒级 | 句式 | 错误例 | 修法 |
|------|------|--------|------|
| ★★★★★ | "不是A，而是B" / "不是A，不是B，而是C" | "他不是冷漠，而是绝望" | 直接写 B 或用更自然的表达 |
| ★★★★ | "，带着……" 万能状语 | "他笑了一下，带着一丝不易察觉的嘲讽" | 拆短句或换动作 |
| ★★★★ | "声音不大，却带着一种……的力量" | "她声音不大，却带着不容置疑的力量" | 直接写声音特征或动作 |
| ★★★★ | "他/她知道……" | "他知道这一切都来不及了" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | "仿佛能穿透一切一般" | 删掉或白描 |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" | 他垂下眼 / 他笑了一下，没到眼底 |
| ★★★ | "心中涌起一股……" / "心头一震" | "心中涌起一股暖流" | 用身体反应 |
| ★★ | 章末预告 "他不知道的是……" | "他不知道的是，更大的风暴即将来临" | 用具体钩子物件/事件收束，避免空泛预告 |

## 五、比喻分类（默认全删）

| 比喻类别 | 例 |
|---------|----|
| 动物类 | "像一头被抛弃的野狗" |
| 物品/现象类 | "像一把刀" "脸色惨白得像这漫天的雪" |
| 状态类（陈词滥调） | "梨花带雨" "如沐春风" |
| 抽象类 | "像命运的齿轮" "像上辈子的尘埃" |
| 假设类 | "力道大得像是要把骨头捏碎" |

**处理原则**：把比喻改为直接描述／动词／名词／作用／结果／事实。例："脸色惨白得像这漫天的雪" → "脸色惨白"。

## 六、替换策略速查

| 原文类型 | 替换方法 | 示例 |
|----------|----------|------|
| 抽象情绪词 | 具体动作 | "紧张" → "手在抖" |
| "感到XX" | 外化表现 | "感到愤怒" → "攥紧拳头" |
| 形容词堆砌 | 白描手法 | "美丽动人的笑容" → "她笑了" |
| 书面表达 | 口语化 | "不容置疑" → "就是" |
| 解释性描写 | 留白 | "他因为害怕而..." → "他退后一步" |
| 连续排比 | 保留最强一条 | 3 句排比留 1 句 |
| 总结升华句 | 直接删除 | "这一刻，她终于明白了..." → 删 |
| "不是A，而是B" | 直接写 B | "他不是冷漠，而是绝望" → 直接写 B |
| 多余修饰 | 删 | "白色的药片" → "药片"；"手里那截链子" → "链子" |

## 八、高频踩雷词（来自 khazix-writer，出现即修）

这些词/句式一出现立刻暴露AI味，必须替换：

| 禁用表达 | 问题 | 替换建议 |
|----------|------|----------|
| "说白了" | AI特别爱用，一出现立刻暴露 | 删掉，直接说 |
| "意味着什么？" | AI标志性句式 | 删掉，或换成具体追问 |
| "这意味着" | 同上 | 换成更口语表达，如"也就是说"、"说到底就是" |
| "本质上" | 太学术 | 删掉，或用"说到底" |
| "换句话说" | 太书面 | 删掉，直接说 |
| "不可否认" | 套话 | 删掉 |
| "综上所述" / "总的来说" | 套话 | 删掉，用动作/场景收尾 |
| "首先...其次...最后" | 三段式 | 打散，用隐性连接 |
| "值得注意的是" / "不难发现" | 套话 | 删掉，直接说内容 |
| "让我们来看看" / "接下来让我们" | 套话 | 删掉，直接进入内容 |
| "在当今...的时代" | 教科书开头 | 换成具体事件切入 |
| "随着技术的不断进步" | 空话开头 | 换成具体事件切入 |
| "比如有一次..." | 假设性例子 | 换成"就像我今天正在搞的..."真实场景 |
| "某个AI工具" / "某个模型" | 空泛工具名 | 换成具体名称（Claude Code、DeepSeek等） |

## 八·五、v4.0 新增信号（来自 B站爆款视频评论区 1400 条真人众测，2026-08-05）

> 以下信号是大众公认的"一眼AI"特征，出现即修。

### 1. "不是A而是B"三毒（最高优先级，详见 SKILL.md 专项章节）
- **毒1 假靶子**："AI 改变的不是工具，而是生产关系。"（没人说过是工具）
- **毒2 同义替换**："她不是在演风，而是在演一种失控感。"（风=失控感）
- **毒3 无关硬凑**："他不是传统的 stalker 片，而是愿望反噬。"
- **NNY 变体**："不是X。不是Y。只是Z。"
- **修法**：删前半句 / 合并同义 / 改"不仅是A更是B" / 直接删

### 2. 高频堆叠副词（一段内重复即修，AI 网文重灾区）
极其、极度、极易、极为、猛地、死死、狠狠、稳稳、偏偏、生生、硬生生、活生生、瞬间、下一秒、那一秒、零点一秒、立刻、此刻、此时、紧接着、骤然、当场、然而、仿佛、如同

### 3. 科普区起手式套话（科普/知识类文章重灾区）
- "先说答案" / "先给你一个结论"（评论区原话：所有科普视频全用这句开头）
- "掰开了揉碎了" / "拆解"（原话：看到"拆解"两个字直接退出）
- "你品一下"（AI 光学了句式，不懂真实含义）
- "看明白了吗" / "看到没有"

### 4. 莫名其妙的比喻（本体喻体毫无逻辑关联）
- "天空像油腻腻的裹尸布"
- "演技像村口老头的烂牙"
- "声音像砂纸在摩擦"
- "精准的手术刀"（形容分析）
- "命运的齿轮" / "石子投湖" / "如潮水般涌来"
- **修法**：AI 只会做词语表面相似性拼接，没有生活经验支撑 → 白描或直接删，换成有真实逻辑关联的表达

### 5. 数字过分具体（假装严谨，实际无意义）
- "一步跨 50cm，这次却跨了 49cm，说明你心虚了"
- "0.3 秒" "0.0几秒" "百分之多少"
- **修法**：删掉假精确数字，或换成正常表达

### 6. 三字鉴定词
- "声音很平" —— 评论区：这三个字一出现，直接鉴定 AI
- 类似："目光一凛" "眼神一凛" "指节泛白" "近乎xx的xx" "带着一丝不易察觉的..."

### 7. AI 不会玩梗（笑话/梗引用生硬）
- 特征：像春晚陈年烂梗的加强版，尬得头皮发麻
- 原因：大部分笑话的冒犯性和好笑程度成正比，AI 要么理解不到笑点，要么不敢冒犯
- **修法**：删掉 AI 式玩梗，或换成有真实冒犯感的表达

### 8. 讨好腔全家桶（AI 客服式共情）
- "我会稳稳地接住你" / "不逃，不躲，不闪避"（ChatGPT 中文口癖，被 P 成救生气垫）
- "你的观察很敏锐" / "我理解你的感受" / "你现在的状态其实很稳"
- "如果你愿意，我可以再帮你" / "先给你一个结论"
- **修法**：礼貌到疏离、客气到生疏 → 换成直接、有具体内容的回应

### 9. 自问自答老师腔（AI 扮老师上瘾）
- "这叫什么？这叫责任的转嫁。"
- "说明什么？说明这5年里，家长批改作业不但没少，反而更普遍了。"
- "怎么办到的？两头不是人。"
- "看明白了吗？""看到没有？"
- **特征**：自己提问自己马上回答，一篇文章能问十次；真人不会这样自导自演
- **修法**：删掉提问，直接陈述观点

### 10. "你以为A，实际上B"（把读者当傻子）
- "你以为孩子拿着手机是在写作业，实际上写完作业就顺手滑进了短视频"
- "你以为等等会降？实际上不可能降下来"
- **特征**：AI 先假装读者有个错误认知，再显摆自己更聪明
- **修法**：删掉前半句"你以为"，直接说 B

### 11. AI 幻觉/假数据（引用看起来很真，查无实据）
- "NASA 的科学家算了一笔账……"（评论区：这种"某机构数据"根本查不到）
- "据某报告显示（视频里没有出现报告），……竟高达……"
- "相关研究表明""大量实践证明"——到底是哪些？没说
- **特征**：引文格式正确但内容虚构，定义听着周全但套谁都行
- **修法**：核实来源；查无实据一律删，换真实可查的数据

### 12. 网文 OOC/设定崩坏（小说类专属信号）
- 角色性格突变、前后矛盾（"把主角的血缘关系删了""明明设定是兄妹，AI 写成了恋人"）
- 私加人设："AI 偷偷给 OC 加设定——金发碧眼就非要配'橘子的香气'，名字带月就非要'月光般温柔'"
- 刻板印象硬塞："活泼女角色必爱粉红色草莓蛋糕兔子""成熟女性必踩高跟鞋大红唇"
- 无意义对话："你这刀法练了多久？""够久。"（刚死里逃生的场景，AI 在装深沉）
- **特征**：AI 把用户给的人物特点无限放大塞到角色身上，ooc 得要命，逻辑不通
- **修法**：严格对照原设定，删除 AI 私加的刻板细节，对话必须有信息量

## 十、推荐口语化词组（自带"活人感"）

> 来源：khazix-writer

### 转场和过渡
坦率的讲、说真的、我是真的觉得、反正我觉得、怎么说呢、其实吧、你想想看、我跟你说、回到xxx这块、这块需要注意一下、顺着上面的再聊聊

### 表达判断
我有时候觉得、我一直觉得、这话听着有点刺耳但、不是说xxx不行而是说、我自己的感受是、我始终坚信、我觉得还是挺重要的

### 承认和自嘲
说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟、这个事儿我也踩过坑、愚钝如我、我说"理论上"是因为我自己还没完全跑通、说实话我们还差得远

### 情绪表达
这种感觉太爽了、我当时就愣住了、想想就觉得兴奋、我真的被震撼到了、搞得我现在还有点懵、太离谱了、给我一下子整不会了、这一下给我更干懵了、一时间无语凝噎、你敢信？？？

### 拉近距离
很多朋友可能不知道、可能有小伙伴纳闷、你如果关注这个领域的话、大家也都知道、看到的兄弟可以把公屏打在弹幕上

### 口头禅和口癖
这玩意、不是哥们、我寻思了一下我没寻思明白、有个屁的xxx、真的就是一声叹息、太牛逼了、比较骚的事
